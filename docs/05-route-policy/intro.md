# 경로 정책 (Route Policy)

## 정의

라우터가 경로를 선택·광고·재배포할 때 **조건(match)** 과 **행동(set)** 을 조합하여 트래픽 흐름과 라우팅 테이블을 제어하는 메커니즘.

## 특징

- **(정책 기반 제어)** 목적지 주소뿐 아니라 메트릭·태그·커뮤니티 등 다양한 속성을 기준으로 경로를 선택적으로 허용·차단·변환
- **(순서 기반 처리)** 경로 정책은 시퀀스 번호 순서로 평가되며 첫 번째 일치 항목에서 처리가 종료되는 first-match 방식으로 동작
- **(멀티 프로토콜 적용)** OSPF·EIGRP·BGP·재배포 등 모든 라우팅 프로토콜에 공통으로 적용 가능하며 프로토콜 간 상호 운용성을 보장

## 경로 정책 도구 비교

| 구분 | ACL | Prefix-List | Route-Map |
|------|-----|-------------|-----------|
| 용도 | 패킷 필터링 / 경로 필터링 보조 | 경로(네트워크 주소) 정밀 매칭 | 매칭 + 속성 변환 (set) |
| 매칭 기준 | IP 주소 + 와일드카드 마스크 | 네트워크 주소 + 프리픽스 길이(ge/le) | ACL·prefix-list·태그·메트릭 등 복합 |
| 속성 변환 | 불가 | 불가 | 가능 (metric, tag, community 등) |
| 순서 번호 | 암묵적 자동 증가 | 명시적 seq 번호 | 명시적 seq 번호 |
| 성능 | 순차 검색 | 이진 트리 검색 (고속) | 순차 검색 |
| 주요 사용처 | 인터페이스 필터, distribute-list | BGP·OSPF 경로 필터링 | 재배포, PBR, BGP 정책 |
